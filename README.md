# Project Overview
A clean, responsive personal portfolio website built with HTML, CSS, and JavaScript. Features a modern design with smooth animations and mobile-friendly navigation.

# ✨ Features
Responsive navbar with hamburger menu (mobile-friendly)

Hero section with profile image and social links

Smooth hover animations and transitions

Lightweight (only 3 files)

Fast loading with minimal dependencies

# 🛠️ Technologies Used
Frontend: HTML5, CSS3, JavaScript

Design: Custom CSS with modern gradients and hover effects

Icons: Image-based (no external icon libraries)
